
Open/Closed Principle (OCP) - Definition

The Open/Closed Principle (OCP) states that:

"Software entities (classes, modules, functions, etc.) should be open for extension but closed for modification."
— Bertrand Meyer

What does it mean?
Open for Extension: You should be able to add new functionality by creating new classes or implementations.
Closed for Modification: Existing, tested code should not need to be changed when adding new features.
Why do we need OCP?
Prevents breaking existing code when adding new features.
Makes the application easier to extend and maintain.
Reduces the chances of introducing bugs into working code.
Encourages flexible designs using interfaces, abstract classes, and polymorphism.

Interview One-Liner

Open/Closed Principle means a class should allow new functionality to be added through extension without modifying its existing source code.
